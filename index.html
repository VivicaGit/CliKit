Instalación y Requisitos Previos

Para usar todas las utilidades necesitas estas herramientas en el sistema:

  • PowerShell 7 (motor donde corren los scripts)
  • FFmpeg (compresión, reparación, extracción de audio y diapositivas)
  • yt-dlp (descarga multimedia)
  • Poppler (extracción de texto de archivos PDF)
  • Python + OpenAI Whisper (motor de IA para transcripción con soporte CPU y GPU NVIDIA CUDA)

Instala las herramientas en Windows ejecutando esto en una terminal de administrador:

winget install --id Microsoft.PowerShell --id Gyan.FFmpeg --id yt-dlp.yt-dlp --id oschwartz10612.Poppler --id Python.Python.3.12 -e && pip install -U openai-whisper

⚡ Aceleración GPU NVIDIA (CUDA): Si dispones de tarjeta gráfica NVIDIA compatible (ej. RTX), puedes habilitar la aceleración CUDA instalando PyTorch con soporte CUDA en Python (pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121) para transcripciones ultrarrápidas.

📸 Extractor Inteligente de Diapositivas: El Modo Apuntes requiere FFmpeg en el PATH para analizar la tasa de cambio de escena y exportar fotogramas clave sincronizados con el audio.
